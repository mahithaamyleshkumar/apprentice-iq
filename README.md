# APPRENTICE IQ
### Proof of Skill. Not Just Proof of Training.

**APPRENTICE IQ** is an AI-powered vocational learning and skill verification platform that bridges the gap between training completion and real-world practical competence.

It combines structured learning, AI-powered assessments, practical skill demonstrations and human verification to make vocational skills measurable, transparent and employer-ready.

## 🚀 Key Features

- **Trade-Specific Learning:** Structured vocational learning pathways and modules.
- **AI Learning Copilot:** Gemini-powered contextual learning assistance.
- **Intelligent Assessments:** Embedded knowledge checkpoints and adaptive oral examinations.
- **AI Practical Skill Vision:** AI-assisted analysis of submitted practical evidence.
- **Skill Gap Intelligence:** Tracks competency progression across four stages.
- **Mentor & Assessor Verification:** Human-reviewed competency approval.
- **Digital Skill Passport:** QR-based verification of approved competencies.
- **Employer Portal:** Access to apprentice profiles and approved skill records.
- **Admin Portal:** Centralised platform management.

## 💡 Core Innovation

APPRENTICE IQ introduces a four-stage competency framework:

| Stage | Meaning |
|---|---|
| Learned | Concept understood |
| Practised | Skill attempted |
| Demonstrated | Practical evidence submitted |
| Verified | Competency approved by an authorised assessor |

**Our approach:** Learning a skill is important. Proving it is what makes it valuable.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS 4
- **Backend:** Node.js, Express.js
- **AI:** Google Gemini API
- **Computer Vision:** MediaPipe Tasks Vision
- **Database:** JSON-based file persistence
- **Authentication:** JWT and scrypt password hashing
- **Visualisation:** Recharts
- **QR Generation:** qrcode

## ⚙️ Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/mahithaamyleshkumar/apprentice-iq.git
```

**2. Navigate to the project**

```bash
cd apprentice-iq
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env` file in the root directory:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Get your API key from [Google AI Studio](https://aistudio.google.com/).

**5. Start the application**

```bash
npm run dev
```

The application automatically initialises its local demo database when one does not exist.

## 🏗️ Core Workflow

```text
LEARN → UNDERSTAND → PRACTISE
       → DEMONSTRATE → VERIFY → PROVE
```

AI supports assessment, while authorised mentors and assessors make final competency decisions.
